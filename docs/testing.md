# 测试指南

本仓库**没有自动化测试**：`build.gradle` 未定义任何测试任务或测试源集，验证以编译 + 手测为主。任何改动至少跑 `gradle compileJava`；发版前 CI 会执行完整 `gradle deploy`。

## 手测清单

改动对应功能后，至少覆盖以下各项：

1. **加载与设置**
   - 模组正常加载（`hidden: true`，不在模组列表显示）。
   - 独立形态：设置 → 模组出现 `Better PolyAI` 分类，含启用、互斥、更新检查四个开关。
2. **开关与快捷键**
   - `P` 键切换开关，出现 `已开启/已关闭` toast；文本输入框聚焦时按 `P` 不误触。
   - 设置页改动约 0.25s 内生效，与快捷键状态一致。
3. **建造辅助**
   - 玩家摆放建造/拆除规划后，操控中的可建造单位自动前往补建；只响应玩家自己的规划。
   - 无效规划（已建/不可建）被自动移除，单位不卡死。
   - 目标超出建造范围时单位自动移动靠近；地面单位按地形/受击正确 boost。
4. **手动移动暂停**
   - 有建造目标时手动移动，出现 `已暂停自主移动` toast；停下约 12 秒后 `已恢复自主移动`。
5. **与 MindustryX 互斥**
   - 安装 MindustryX 且 AuxiliaryTools 选中 BuilderAI：出现 `让出` toast，单位交还 X 端控制；取消选择后恢复。
   - 关闭 `bpa-mutex-with-x-polyai` 后不让出。
6. **更新检查（仅独立形态）**
   - 本地版本低于最新 Release 时弹窗（或 toast，取决于设置）；点 Ignore 后同版本不再提示；6 小时内不重复请求。
   - Neon 聚合形态下完全不触发，且不出现独立设置分类（设置并入 Neon 总页）。
7. **安卓包**
   - 安装 `jarAndroid` 产物可加载（验证 `classes.dex` 有效）。
